# 龙爷的大肥鱼

Android 本机聊天应用的正式安装包与更新清单。

## 安装与更新

从 [最新发布](https://github.com/longye-hub/fat-fish-releases/releases/latest) 下载正式 APK。Android 9 及以上，已在 Android 15 模拟器测试，真机兼容性仍需用户验证。

首次换设备：在旧设备创建加密 `.fatfish` 备份，在新设备安装正式版并恢复，再自行填写 API Key。备份不包含 API Key。保管好密码；恢复会替换新设备中已有的应用资料。

后续正式版本：在应用“备份与更新”中检查更新，核验安装包后由 Android 确认覆盖安装。不要先卸载。测试签名版不能直接覆盖为正式签名版，应使用备份迁移。

## 数据边界

本仓库仅分发通用 APK、版本清单、校验值和说明，不存放个人聊天、记忆、截图、数据库、备份、API Key、签名私钥或密码。

应用数据保存在设备本机的加密数据库。软件更新请求只获取公开版本信息和安装包，不上传聊天或凭据。正常聊天会向用户配置的模型服务发送本轮选中的文字上下文。

加密备份包含原始文件包；单独导出原始 ZIP 或 Markdown 是明文。图片原件可保存，当前没有 OCR 和图片理解功能。没有账号云同步。
